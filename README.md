### 🛠️ ТЕХНИЧЕСКИЙ СТЕК

**1. Управление версиями и совместная разработка**
*   **VCS:** Продвинутое владение **Git** (ветвление, merge, rebase, cherry-pick, работа с конфликтами).
*   **Workflows:** Опыт работы с методологиями **GitFlow** и **Trunk-based development**.
*   **Versioning:** Использование **Semantic Versioning (SemVer)** для управления версиями приложений и инфраструктурного кода.
*   **Platforms:** Глубокая экспертиза в **GitHub** и **GitLab** (Self-managed и SaaS).

**2. Оркестрация и Контейнеризация**
*   **Kubernetes:** Администрирование, развертывание через **Kubespray**, управление через **Helm**, настройка Ingress (Nginx), управление ресурсами (Requests/Limits), ConfigMaps/Secrets.
*   **Docker Swarm:** Настройка и поддержка кластеров для легких микросервисных решений.
*   **Контейнеризация:** **Docker**, **Docker Compose**, создание оптимизированных образов (multi-stage builds).
*   **Registries:** Управление реестрами образов (**Docker Hub**, **Yandex Container Registry**, **GitLab Registry**).

**3. Инфраструктура как код (IaC) и CI/CD**
*   **IaC:** Развертывание облачных ресурсов через **Terraform** (VPC, Compute Cloud, Object Storage S3).
*   **Configuration Management:** Автоматизация настройки серверов через **Ansible** (роли, плейбуки, динамический инвентарь).
*   **CI/CD:** Проектирование и внедрение пайплайнов в **GitHub Actions** и **GitLab CI**.

**4. Базы данных и Middleware**
*   **SQL:** Администрирование **PostgreSQL** и **MySQL**.
*   **Caching:** Ускорение работы приложений через **Redis** (кэширование запросов, хранение сессий).
*   **OLAP:** Работа с **ClickHouse** для обработки больших объемов логов и аналитики.
*   **Brokers:** Понимание принципов работы очередей через **RabbitMQ**.

**5. Обсервабилити (Мониторинг и логирование)**
*   **Metrics:** Построение дашбордов в **Grafana** на основе данных из **Prometheus**.
*   **Logging:** Централизованный сбор логов через **Loki** / **Promtail** / **ELK Stack**.

**6. Системный уровень**
*   **OS:** Продвинутое администрирование **Linux** (Debian, Ubuntu, CentOS).
*   **Networking:** Знание модели OSI, TCP/IP, DNS, настройка балансировщиков нагрузки.
*   **Scripting:** Написание скриптов на **Bash** и **Python** для автоматизации рутины.

### 🚀 КЛЮЧЕВЫЕ ПРОЕКТЫ

#### 💎 Дипломный проект: "Infrastructure as Code & CI/CD"
*   **Задача:** Спроектировать и развернуть отказоустойчивую среду в Yandex Cloud.
*   **Решение:** С помощью **Terraform** и **Ansible** развернут кластер **K8s**. Настроен CI/CD пайплайн, версионирующий каждый этап сборки. Реализован стек мониторинга.
*   **Результат:** Время развертывания новой версии приложения сокращено с часов до минут.
*   **[Репозиторий проекта](https://github.com/Dmitriy-py/Graduation-project)**
*   **Задача:** С нуля спроектировать и развернуть полноценную инфраструктуру для изучения и практического применения DevOps-инструментов.
*   **Решение:** Развернут сервер виртуализации Proxmox. ВМ с Ubuntu Server для кластера Kubernetes (K3s) и для GitLab (Self-Managed). Настроены пайплайны CI/CD в Jenkins, автоматический деплой через ArgoCD в Kubernetes. Обеспечен внешний доступ к сервисам (например, через Nginx Ingress).
*   **Итоги:** Создана стабильная, отказоустойчивая и полностью управляемая среда для разработки и тестирования проектов, позволяющая автоматизировать весь цикл поставки ПО.
Использованные технологии: Proxmox, K3s, Kubernetes, Jenkins, ArgoCD, GitLab, Docker, Nginx Ingress, WireGuard, Linux.

  #### ⚡ Оптимизация производительности систем хранения
*   **Кейс:** Внедрение **Redis** для снижения нагрузки на **PostgreSQL** и настройка **ClickHouse** для мгновенного анализа логов системы.
*   **Итог:** Повышена стабильность работы БД и прозрачность всей инфраструктуры.
