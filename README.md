### 🛠️ ТЕХНИЧЕСКИЕ НАВЫКИ

**1. Оркестрация и Контейнеризация**
*   **Kubernetes:** Развертывание кластеров (Kubespray), администрирование, работа с Ingress, манифестами и секретами.
*   **Docker Swarm:** Настройка кластеров, управление стеками и сервисами.
*   **Docker / Docker Compose:** Глубокая экспертиза в контейнеризации приложений и оптимизации образов.

**2. Инфраструктура как код (IaC) и Управление конфигурациями**
*   **Terraform:** Декларативное описание инфраструктуры в Yandex Cloud (VPC, Compute, Storage).
*   **Ansible:** Написание идемпотентных плейбуков и ролей для автоматизации настройки серверов.

**3. CI/CD (Непрерывная интеграция и доставка)**
*   **GitHub Actions / GitLab CI:** Построение полных циклов автоматизации (сборка, тестирование, деплой).

**4. Базы данных**
*   **SQL:** Администрирование и развертывание **PostgreSQL**, **MySQL**.
*   **OLAP:** Работа с **ClickHouse** для высокопроизводительной аналитики и хранения логов.

**5. Мониторинг и Логирование (Observability)**
*   **Prometheus / Grafana:** Сбор метрик и визуализация состояния систем.
*   **Loki / Promtail / ELK:** Централизованное управление логами.

**6. Системное администрирование**
*   **Linux:** Уверенное администрирование систем семейства Debian/Ubuntu/CentOS.
*   **Scripting:** Bash, Python (автоматизация рутинных задач).

### 🚀 КЛЮЧЕВЫЕ ПРОЕКТЫ

#### 💎 Дипломный проект: "Отказоустойчивая инфраструктура в Yandex Cloud"
*   **Задача:** Создать масштабируемую среду для веб-приложения с нулевой точкой отказа.
*   **Решение:** Через **Terraform** развернута сеть в 3-х зонах доступности. Кластер **Kubernetes** поднят с помощью **Kubespray**. Настроен автоматический деплой через **GitHub Actions**.
*   **Результат:** Реализована полностью автоматизированная среда с внедренным мониторингом (**Prometheus/Grafana**) и сбором логов (**Loki**).
*   **[Ссылка на код проекта](https://github.com/Dmitriy-py/Graduation-project)**

#### 📊 Система сбора и анализа данных
*   **Задача:** Оптимизировать работу с логами и метриками в распределенной среде.
*   **Решение:** Использование **Docker Swarm** для оркестрации сервисов. Внедрение **ClickHouse** как высокопроизводительного хранилища.
*   **Результат:** Настроена стабильная аналитическая подсистема с быстрым поиском по терабайтам логов.
