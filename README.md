### 🎯 Профессиональный профиль

Я — **DevOps-инженер** с «красным» дипломом Нетологии и серьезным инженерным бэкграундом (**КИПиА**). Моя специализация — проектирование отказоустойчивых систем и полная автоматизация инфраструктурных процессов.

*   **Infrastructure as Code (IaC):** Проектирую облачные среды, которые легко масштабировать и восстанавливать.
*   **Опыт в КИПиА:** Привношу инженерную точность в цифровую среду — для меня uptime и надежность всегда на первом месте.
*   **Стек:** Работаю с современным набором инструментов (K8s, Terraform, Ansible) и базами данных (PostgreSQL, ClickHouse).

### 🚀 Ключевые кейсы

#### 💎 Дипломный проект: "Infrastructure-as-Service в Yandex Cloud"
> Автоматизированная среда для высоконагруженного приложения.
*   **Сетевая топология:** Развернута в 3-х зонах доступности через **Terraform**.
*   **Kubernetes:** Bare-metal установка через **Ansible/Kubespray**, настройка контроллеров трафика.
*   **Observability:** Внедрена система мониторинга и сбора логов (Prometheus/Loki/Grafana).
*   **CI/CD:** Полный цикл деплоя приложения из GitHub прямо в кластер.
*   **[🔗 Посмотреть код проекта](https://github.com/Dmitriy-py/Graduation-project)**

#### 📊 Аналитическая система логирования
> Оптимизация хранения и анализа больших данных.
*   Внедрил **ClickHouse** для обработки логов, что позволило существенно ускорить аналитические запросы.
*   Настроил сбор логов через **Promtail** в контейнеризированной среде **Docker Swarm**.
